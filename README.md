# Oitavo Projeto – Empresa TudoWEB - Pesquisa de satisfação

Este projeto em **Python** foi desenvolvido para praticar o ciclo **Entrada → Processamento → Saída**.  

O programa classifica o a satisfação dos clientes no atendimento

---

## 📋 Objetivo
- Receber informações sobre como foi o atendimento.
- Processar os dados para analise final de satisfação.
---

🛠️ Tecnologias Utilizadas
Python 🐍

Estruturas condicionais (for, estudado também while)

Funções de entrada e saída (input, print)
